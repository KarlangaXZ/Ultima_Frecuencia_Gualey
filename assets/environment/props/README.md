# Arte final de obstáculos

Carpeta reservada. Reasignar `Obstacle/Visual.texture`; mantener su huella de
128 × 96 o ajustar solo la escala del sprite para conservar el tamaño visible.
No escalar el StaticBody2D ni cambiar la colisión para acomodar el dibujo.
[Guía de recursos](../../README.md).

Fase 4.5: UrbanObstacle.tscn añade props y edificios geométricos provisionales.
Su script solo dibuja; toma el tamaño de CollisionShape2D. Para integrar sprites,
sustituir ese dibujo conservando la huella y posición del cuerpo. No hay imágenes
finales de edificios, carros, contenedores, barricadas ni postes en esta carpeta.
Ver [validación urbana](../../../docs/urban_world_integration.md).
